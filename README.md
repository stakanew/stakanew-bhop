# stakanew's BHop Script

Мощный BHop скрипт для Roblox с визуальными эффектами и удобным GUI меню.

## Возможности

### BHop
- Автоматический прыжок при касании земли
- Настройка скорости на земле (10-100)
- Настройка скорости в воздухе (1-50)
- Не меняет гравитацию игры

### Визуалы
- Круг при прыжке (расширяющийся диск)
- Копия игрока при прыжке (замороженная)
- След за игроком (непрерывная линия)

### Меню
- Удобное GUI меню (кнопка S)
- Вкладки BHop и Visuals
- Переключатели и слайдеры
