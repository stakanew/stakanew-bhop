# stakanew's BHop Script

Многофункциональный чит-скрипт для Roblox с системой BHop, визуальными эффектами, Spinbot, RGB-подсветкой и меню настроек.

## Возможности

### 🏃 BHop
- Автоматический BHop с настраиваемой скоростью
- Ускорение на земле и в воздухе
- Настройка силы прыжка и гравитации
- Авто-отключение стандартных анимаций (опционально)
- Spinbot — вращение персонажа

### 🎨 Визуалы
- **Круг при прыжке** — расширяющийся неоновый круг
- **Копия при прыжке** — замороженная копия персонажа
- **След за игроком** — непрерывный неоновый след
- **Шляпа** — конусообразная шляпа (ConeHandleAdornment) с настройками размера, высоты, прозрачности и скорости вращения
- **RGB режим** — переливание цветов для всех визуалов

### ⚙️ Настройки
- Удобное GUI меню на русском и английском
- Вкладки: BHop, Visuals, Config, Settings
- Слайдеры, переключатели, цветовые палитры
- Сохранение и загрузка конфигураций
- Перезапись существующих конфигов
- Сброс всех конфигов
- Выбор языка интерфейса
